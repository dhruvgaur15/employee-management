# Employee Management App

Full-stack React + TypeScript + Node.js + Express + MySQL assignment.

## Structure

- `ui/` — React + Vite + TypeScript frontend
- `api/` — Node.js + Express + TypeScript backend


### UI
React, TypeScript, Vite, SCSS, React Hook Form, Zod, Highcharts, Vitest, React Testing Library.

### API
Node.js, Express, TypeScript, MySQL (`mysql2`).


Clone the repo > run npm i for both folders seprately > configure DB in api/.env > npm run dev
